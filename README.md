## Built with

Plain HTML, CSS and JavaScript in a single `index.html` file. No frameworks, no build step. Fonts (Syne and DM Sans) load from Google Fonts.

Highlights: animated hero text, scroll reveal effects, pointer-following glow, 3D card tilt, and a clickable content calendar. Respects `prefers-reduced-motion` and works on mobile.

## Run locally

Download or clone the repo and open `index.html` in any browser.

## Deploy

Hosted with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
